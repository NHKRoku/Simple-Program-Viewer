# Simple ProgramViewer

XMLTV をバックエンドとして利用し、ブラウザ上でテレビ番組表（EPG）を簡単に閲覧できるシンプルな Web アプリケーションです。

## ✨ 特徴

- XMLTV 形式の番組データに対応
- ブラウザから簡単に番組表を閲覧
- XMLTV ファイルの URL を指定するだけで処理を開始
- Node.js ベースの軽量な構成

## 🛠️ 必要な環境

- [Node.js](https://nodejs.org/)（npm を含む）
- XMLTV 形式の番組データを提供する URL

## 📦 インストール

### 1. プロジェクトのダウンロード

GitHub から ZIP ファイルをダウンロードして解凍するか、Git を使用してクローンします。

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. 依存パッケージのインストール

プロジェクトのディレクトリで以下のコマンドを実行します。

```bash
npm install express axios xml2js
```

### 3. アプリケーションの起動

```bash
node epg.js
```

### 4. ブラウザでアクセス

ブラウザを開き、以下の URL にアクセスします。

http://127.0.0.1:8000

### 5. 番組表の表示

1. XMLTV ファイルの URL を入力します。
2. 「処理」ボタンをクリックします。
3. データの処理が完了したら、番組表を閲覧します。

## 📁 プロジェクト構成

```text
Simple-ProgramViewer/
├── epg.js          # アプリケーションのエントリーポイント
└── README.md       # プロジェクトの説明と使用方法
```

※ 実際のファイル構成に合わせて必要に応じて修正してください。

## ⚠️ 注意事項

- XMLTV ファイルの URL にアクセスできることを確認してください。
- 番組データの形式やサイズによって、処理に時間がかかる場合があります。
- ポート `8000` がほかのアプリケーションで使用されていないことを確認してください。
